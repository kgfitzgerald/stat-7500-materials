Goals

The main goal of this assignment is to practice a reproducible workflow for working with data in R: importing data, checking that R interpreted it appropriately, analyzing relevant variables, and communicating what you learn.

You will…

  • Import data from an external file using a relative path
  • Inspect the structure and contents of imported data
  • Use data documentation to identify values that represent missingness
  • Distinguish between how R stores a variable and what the variable means
  • Use vectors, indexing, and summary statistics to investigate change over time
  • Export and verify a prepared data file
  • Create and interpret scatterplots
  • Map variables to aesthetic features of a visualization
  • Compare color and faceting as alternative ways to display a third variable

The individual R commands matter, but the larger goal is to develop a reliable process: understand where the data came from, inspect before analyzing, make purposeful choices, and interpret results in context.

Data: Patient Health-Awareness Scores

The patient data were assembled from instructional files previously used in the SAS portion of STAT 7500. They should be treated as instructional data rather than as records from a documented research study.

The file contains records for thirty patients who participated in a six-week health-awareness program. Health-awareness surveys were administered before and after the program. Scores range from 0 to 20, with higher scores indicating greater awareness of healthy habits.

The variables in patients.csv are:

  • patient_id: unique patient identification code
  • gender_code: gender recorded as 0 for male and 1 for female
  • baseline_score: health-awareness score before the program
  • followup_score: health-awareness score after the program

The data documentation also tells us that:

  • Not recorded represents a missing gender value; and
  • . represents a missing survey score.

Identifying missing values during import

Missing data in R are represented by NA. However, external files may use many different values to indicate missingness. We should use the data documentation—not guesswork—to determine what those values mean.

NoteExercise 3

Import patients.csv again and assign the result to an object named patients.

This time, use the na argument in read_csv() to identify "Not recorded" and "." as missing values.

Use glimpse() and summary() to inspect patients, and then respond to the following:

  • Which variables changed type and why?
  • Did identifying the missing values change the number of rows or columns? Why or why not?
  • Although gender_code is now stored as a numerical variable, should it be interpreted as a quantitative measurement? Explain.
  • What does this example demonstrate about the difference between a variable’s storage type and its meaning?

A value such as . is not universally a missing value. We treat it as missing here because the data documentation tells us what it represents in this particular file.

Investigating change over time

The survey was administered to the same patients before and after the program. Therefore, each patient’s follow-up score should be compared with that same patient’s baseline score.

NoteExercise 4

Create a vector called score_change by subtracting each patient’s baseline score from their follow-up score:

score_change <- patients$followup_score - patients$baseline_score

Then:

  • Print score_change.
  • Print only the fifth element using [] notation.
  • Verify that score_change is numerical using class().
  • Use summary() to inspect the distribution of the change scores.
  • Use appropriate summary statistic function (e.g. mean()) to reproduce the mean, median, minimum, and maximum printed out by summary(). Handle missing values appropriately.
  • Explain why score_change contains a missing value. Does that missing value represent a patient whose score did not change?
  • In 2–3 sentences, describe what the results suggest about changes in health-awareness scores.
  • Do these summaries alone establish that the program caused the observed changes? Explain briefly.

A positive value of score_change indicates that the patient’s score increased. A negative value indicates that it decreased. A value of zero indicates no change.
